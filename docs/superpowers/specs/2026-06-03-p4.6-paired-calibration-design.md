# P4.6 — Lab: Paired AI-on / AI-off Calibration (cell 2.15)

**Phase:** P4.6 — *Paired timed tasks (with/without Claude); capture subjective vs. actual time + defects → calibration number.*
**Depends on:** P4.1 (the generalized lab pattern). Not P4.2 — the calibration number is computed, not LLM-judged.
**Date:** 2026-06-03
**Branch:** `feat/p4.6-paired-calibration`

## 1. Goal

Build the paired AI-on/AI-off calibration exercise for cell 2.15. The learner
does two comparable tasks in-app — one **without AI** and one **with Claude** —
each timed by the app. They then estimate how much faster AI made them and enter
a defect count per task. The app computes a **calibration number**: the gap
between the learner's estimated speedup and their actual measured speedup
(matching the cell's lesson — e.g. felt 40% faster, actually 15% → a 25-point
gap). The result is recorded as a lab submission.

Out of scope: LLM-as-judge grading of the work (P4.6 produces a *computed*
calibration number, not an anchor score); gating completion (2.15's inline quiz
remains the gate); other cells.

## 2. Context (current state)

- **Exercise pattern (P4.3–P4.5):** interactive exercises are `LabConfig` union
  members (keyed by `kind`) stored in `modules.lab_config_json`, rendered by
  `ModuleRenderer.renderExercise()` (a switch on `module.labConfig?.kind`).
  Components live in `src/components/exercises/`, take `{ config, labId }` ONLY
  (no `onComplete`), call `recordLabSubmission`, and leave completion to the
  cell's inline quiz. `IterationLab.tsx` is the closest analog: it integrates
  Claude via `streamChat` and records a submission.
- **`recordLabSubmission(userId, { labId, transcript, status })`** inserts into
  `lab_submissions` (owner-only RLS) and returns the new row id.
- **Cell 2.15** ("Paired AI-on / AI-off calibration") is `type='content'` with an
  authored lesson and an inline quiz (the completion gate). The lesson defines
  the exercise precisely: do one task with AI and one without; record subjective
  speedup estimate, actual elapsed time, and defect count for each; the
  calibration number is the estimate-vs-actual gap.
- **Naming caution:** a `calibration.grade.ts` / `Calibration.tsx` already exist
  for the *confidence*-calibration lab (cell 2.8, P4.3c) — unrelated. P4.6 uses
  distinct names (`PairedCalibration`, `pairedCalibration.compute.ts`).
- **No local Anthropic key** in this environment (the `chat`/judge calls 401) —
  the AI-on phase's Claude call will error locally, but the timer/flow/calibration
  do not depend on Claude succeeding.

## 3. Decisions

| # | Decision | Choice |
|---|----------|--------|
| D1 | Completion model | **Supplementary exercise.** `{ config, labId }` props, no `onComplete`; records a `lab_submission`; 2.15's quiz gates. Mirrors P4.3–P4.5. |
| D2 | Timing | **App-timed, in-app.** Both tasks are done in the app with a Start/Stop (live `mm:ss`) timer; actual elapsed is `Date.now()` difference, not learner-entered. |

| D6 | Content | Two comparable civic-tech tasks seeded on 2.15's config, drafted for SME review (`status='in_review'`); lesson/quiz untouched. |

## 4. Config type + calibration computation (§1)

**`src/types.ts`** — new union member:

```ts
export interface PairedCalibrationConfig {
  kind: 'paired-calibration';
  intro?: string;
  offTask: { label: string; brief: string }; // done WITHOUT AI
  onTask: { label: string; brief: string };  // done WITH Claude (comparable, not identical)
}
```

Added to `export type LabConfig = … | PairedCalibrationConfig;`.

**Pure helper `src/components/exercises/pairedCalibration.compute.ts`:**

```ts
export interface CalibrationInput { offMs: number; onMs: number; estimatePct: number }
export interface CalibrationResult { actualSpeedupPct: number; gapPct: number }
export function computePairedCalibration(input: CalibrationInput): CalibrationResult;
```

- `actualSpeedupPct = Math.round((offMs - onMs) / offMs * 100)` — positive = AI
  faster; negative if AI was slower.
- `gapPct = Math.abs(estimatePct - actualSpeedupPct)`.
- Guard: `offMs <= 0` → `actualSpeedupPct = 0` (no divide-by-zero).
- Matches the lesson's worked example (off vs. on yielding 15% actual, estimate
  40% → gap 25). Unit-tested.

## 5. Component + wiring (§2)

**`src/components/exercises/PairedCalibration.tsx`** — `{ config, labId }`,
FailureSpotter/IterationLab card style, a small phase state machine:

1. **Intro** — `config.intro` + both task briefs; "Start without AI" button.
2. **AI-off phase** — `offTask.brief` + a textarea for the learner's work + a
   live `mm:ss` timer (started on entry); no Claude. "Done" stops the timer and
   stores `offMs` (elapsed is not shown back yet).
3. **AI-on phase** — `onTask.brief` + a prompt textarea with **Run**
   (`streamChat` → streamed output, like `IterationLab`) so the learner uses
   Claude, plus the live timer. "Done" stops and stores `onMs`.
4. **Self-report** — defect-count number inputs (off / on; "count what a reviewer
   would flag") and the estimate input *"How much faster (%) do you think AI made
   you?"* — shown **before** any actual time.
5. **Reveal** — `computePairedCalibration({ offMs, onMs, estimatePct })`; show
   **"You felt N% faster · You were actually M% · Calibration gap: G points"**
   with the lesson's framing (and, if AI was slower, say so plainly). Then
   `recordLabSubmission(user.id, { labId, transcript: { offMs, onMs, offOutput, onPrompt, onResponse, offDefects, onDefects, estimatePct, actualSpeedupPct, gapPct }, status: 'submitted' })`.
   A "Start over" resets. **No `onComplete`.**

Timer: store `startedAt` (epoch ms) on phase entry + a 1s tick for the live
display; elapsed = `Date.now() - startedAt` on "Done" (display is cosmetic). A
Claude failure in the AI-on phase shows an inline error but never blocks stopping
the timer or proceeding. `if (!user)` guard + non-blocking save error, like the
other exercises.

**`ModuleRenderer` wiring** — add to `renderExercise()` + import:

```tsx
case 'paired-calibration':
  return <PairedCalibration config={module.labConfig} labId={module.cellId} />;
```

No `onComplete`; no other case changes.
