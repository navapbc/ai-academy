# P5.3b — Calibration number + portfolio on the learner self-view

**Item:** Phase 5 slice P5.3b (second slice of P5.3 Learner dashboard).
**Date:** 2026-06-17 · **Branch:** `feat/p5.3b-calibration-portfolio`
**Depends:** P5.3a learner self-view (merged, #83).

## Goal

Surface, on the learner's own "My progress" dashboard, the artifacts the Stage-2
practice instruments produce: the **PairedCalibration number** (2.15) and the three
portfolio instruments — **confidence calibration** (2.8), the **failure-mode log**
(2.9), and the **use-case library + 4D Diligence Statement** (2.11). These already
persist to `lab_submissions.transcript` but are surfaced nowhere learner-facing
(the P5.2c drill-down deliberately reads badges only; transcript reading was
deferred). This closes that gap for the *learner's own* artifacts.

## Decisions

- **Owner RLS, no new policy/migration.** All four instruments write to
  `lab_submissions` (owner-only RLS). The reader selects `transcript` for the
  learner's own rows (`userId` = signed-in user) — the same owner-RLS path P5.3a
  uses. No new policy, view, or migration. (Staff transcript reading stays a P5.5
  review-queue concern; this is self-only.)
- **Latest submission per instrument.** A learner may re-submit; the dashboard shows
  the most recent artifact per `lab_id` (order by `created_at desc`, take first).
- **Defensive parsing.** `transcript` is free-form `jsonb` (typed `unknown` on read).
  Each artifact has a pure parser with type guards that returns `null` on a
  shape mismatch (old/partial rows), so a malformed transcript degrades to "not
  submitted yet" rather than crashing the view (W2-7 spirit).
- **Separate reader + hook, additive.** New `learnerPortfolio.ts`
  (pure parsers + `fetchLearnerPortfolio`) and `useLearnerPortfolio` hook — the
  shared `fetchLearnerDetail` (P5.2c, also used by staff) is left untouched.
- **Read-only.** Records nothing, no `onComplete`, no gating effect — pure display.

## Architecture

### `src/lib/learnerPortfolio.ts` — pure parsers + data-access

Parsed artifact types (each carries `createdAt`):
- `PairedCalibrationArtifact` — `gapPct` (the calibration number = |estimate −
  actual speedup|), `actualSpeedupPct`, `estimatePct`, `offMs`, `onMs`,
  `offDefects`, `onDefects`.
- `ConfidenceCalibrationArtifact` — `calibrated/over/under/unanswered`, `score`,
  `maxScore`.
- `FailureLogArtifact` — `entries[]` (`date/task/error/caught/tell`), `entryCount`.
- `UseCasePortfolioArtifact` — `entries[]` (`verdict/task/approach/watch`),
  `statement` (dimension id → text), `helpsCount/doesntCount/wordCount`.

`buildLearnerPortfolio(rows)` (pure): picks the latest row per lab id and parses →
`LearnerPortfolio { pairedCalibration, confidenceCalibration, failureLog,
useCasePortfolio }` (each nullable). `fetchLearnerPortfolio(userId)` reads
`lab_submissions (lab_id, transcript, created_at)` for `lab_id in
('2.15','2.8','2.9','2.11')`, ordered desc, then `buildLearnerPortfolio`.

### `src/lib/useLearnerPortfolio.ts` — fetch state hook

Mirrors `useLearnerDetail` (loading/error/reload), keyed on userId.

### `src/components/progress/LearnerPortfolio.tsx` — presentational

Four sub-panels, each with a friendly empty state ("Complete the 2.x lab to see it
here"):
- **Calibration (2.15):** the gap number front-and-centre with a plain-language read
  ("you estimated X%, actual was Y% — a Z-point gap"), plus defects on/off.
- **Confidence calibration (2.8):** calibrated / over-reliant / under-reliant counts
  + score.
- **Failure-mode log (2.9):** the dated entries (task / what went wrong / how caught
  / the tell).
- **Use-case portfolio (2.11):** the library entries (helps / doesn't) + the 4D
  Diligence Statement (Delegation / Description / Discernment / Diligence — labels
  from a small id→label map, title-case fallback).

### Wiring

`LearnerDashboard.tsx` (P5.3a) gains a "Your portfolio & calibration" section that
renders `<LearnerPortfolio userId={userId} />`. No new `View`, no sidebar change.

## Testing

- **Unit** (`learnerPortfolio.test.ts`): each parser — happy path, missing/garbage
  transcript → null, `buildLearnerPortfolio` latest-per-lab selection.
- **Component** (`LearnerPortfolio.test.tsx`, jsdom): mocks `fetchLearnerPortfolio`;
  asserts each artifact renders and the empty states show when absent.
- **E2E** (extend `e2e/16-learner-dashboard.spec.ts`): the "Your portfolio &
  calibration" section renders on the demo learner's dashboard.
- **No regression**: P5.3a + staff `LearnerDetail` tests stay green (untouched
  shared path).

## Non-regression / conventions

- Additive: new files + a new section in `LearnerDashboard`. No change to
  `fetchLearnerDetail`/staff path. No new RLS/policy/migration; owner RLS only.
- Zero `any`; defensive `unknown`-typed parsing. `P5.3b` ids in comments.
