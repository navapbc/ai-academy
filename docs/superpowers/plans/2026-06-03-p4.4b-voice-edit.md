# P4.4b — Voice-edit Lab Implementation Plan

> **For agentic workers:** implement task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. See the design spec: `docs/superpowers/specs/2026-06-03-p4.4b-voice-edit-design.md`.

**Goal:** Add a `VoiceEdit` exercise on cell 2.6 — read a dense source + a writing brief, generate an AI first draft live (`streamChat`), revise it "AI off" in your own voice, and get the revision graded in place by the P4.2/#48 LLM-judge — graded practice that records a `lab_submission` but does NOT gate completion (the inline quiz stays the gate). Reuse `GradeResultCard` + `streamChat` + the judge; no judge change (the `{brief, sections[]}` judge already fits three sections). Content is seeded as data via a migration.

**Architecture:** A focused `VoiceEdit` component (not an extension of `SourcedFreeTextLab` — see spec D1). Phase 1 mirrors `Lab.tsx`'s streaming generate (model selector + `abortRef`/`useEffect` cleanup + per-run `AbortController`). Phase 2 mirrors the #51 save→grade→`GradeResultCard` flow with a prefilled revision textarea and a three-section judge submission (`Source` + `AI first draft` + `revision`). Rendered above the quiz; no `onComplete`.

**Tech Stack:** React 19 + Vite, TypeScript, Supabase Edge Functions (Deno), Postgres migrations; Vitest (jsdom for components); Playwright (`chat` + `grade` stubbed at the network layer).
