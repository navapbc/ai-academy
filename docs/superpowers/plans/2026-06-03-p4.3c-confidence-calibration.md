# P4.3c — "Confidence-calibration" Lab (cell 2.8) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax. Design rationale + the SME-reviewed answer key live in `docs/superpowers/specs/2026-06-03-p4.3c-confidence-calibration-design.md`.

**Goal:** Add an auto-graded confidence-calibration exercise — `Calibration` — to cell 2.8. The learner sets a verification posture for several outputs from the SAME AI tool; deterministic grading against an answer key (no LLM) reports an over-/under-reliance summary. Records a `lab_submission` but does NOT gate completion — the inline quiz stays the gate.

**Architecture:** Additive only. A new `CalibrationConfig` member on the `LabConfig` union, a pure unit-tested grader (`calibration.grade.ts`, over/under = sign of `pickedIndex − targetIndex` on an ordered scale), a self-contained `Calibration` component (renders items, auto-grades on Submit, reveals per-item `why` + an over/under summary card, records the submission, **no `onComplete`**), one `ModuleRenderer` dispatch case, and a content-as-data seed migration. Mirrors P4.3a's `output-audit`. **No P4.2/P4.3b shared grading code is touched.**

**Tech Stack:** React 19 + Vite, TypeScript, Supabase Postgres migrations; Vitest for the grader + components; Playwright for the slice.
