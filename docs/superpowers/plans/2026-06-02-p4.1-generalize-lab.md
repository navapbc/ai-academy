# P4.1 — Generalize the Lab Component Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refactor the bespoke 2.1 lab (`PromptLab`) into a reusable, config-driven `Lab` component (de-hardcoded `labId` + header) so later Stage-2 labs can be added by extending `LabConfig`.

**Architecture:** Rename `PromptLab.tsx` → `Lab.tsx`; the generic shell (model selector, Claude `streamChat` run, streamed output, Save & complete) stays, while `labId` comes from a prop (`module.cellId`) and the header from optional config `title`/`subtitle` (resolved by a pure `labHeader` helper). A small migration sets 2.1's `title`/`subtitle` so its header is unchanged. No grading (that's P4.2).

**Tech Stack:** React 19 + Vite, TypeScript, Tailwind, motion, lucide-react; Supabase Postgres migrations; Vitest for the pure helper; Playwright for the in-app run (real Claude call via the chat Edge Function).

```javascript
import { chromium } from 'playwright';
const BASE = 'http://127.0.0.1:3000';
const browser = await chromium.launch({ channel: 'chrome' });
const page = await browser.newPage();
try {
  await page.goto(BASE, { waitUntil: 'networkidle' });
  await page.fill('#email', 'demo@navapbc.com');
  await page.fill('#password', 'demo-password');
  await page.getByRole('button', { name: 'Sign In', exact: true }).click();
  await page.waitForSelector('text=Sign out', { timeout: 10000 });
  await page.waitForTimeout(1500);

  // Open cell 2.1 (title contains "Prompt construction as a craft").
  await page.getByText('Prompt construction', { exact: false }).first().click();
  await page.waitForSelector('#prompt-lab', { timeout: 5000 });
  const headerOk = await page.getByText('Prompt Construction', { exact: false }).first().isVisible().catch(() => false);
  console.log('2.1 lab header "Prompt Construction" shown:', headerOk);

  // Write a prompt and run it against Claude.
  await page.locator('#prompt-lab textarea').fill('In 3 bullet points at an 8th-grade reading level, explain what a SNAP recertification notice is. No jargon.');
  await page.getByRole('button', { name: 'Run prompt' }).click();
  // Wait for streamed output to appear (Run button returns from "Running…").
  await page.waitForSelector('button:has-text("Run prompt")', { timeout: 30000 });
  await page.waitForTimeout(1000);
  const outputLen = (await page.locator("#prompt-lab >> text=Claude's Output").count()) > 0;
  console.log('Claude output panel present:', outputLen);

  // Save & complete.
  await page.getByRole('button', { name: /Save & complete/ }).click();
  await page.waitForTimeout(1500);
  const savedOk = await page.getByText('Saved & completed', { exact: false }).first().isVisible().catch(() => false);
  console.log('Saved & completed shown:', savedOk);
  await page.screenshot({ path: '/tmp/p41-lab.png' });

  console.log(headerOk && outputLen && savedOk ? 'RESULT: PASS' : 'RESULT: FAIL');
  await browser.close();
} catch (e) {
  console.log('ERROR', e.message);
  await page.screenshot({ path: '/tmp/p41-error.png' }).catch(() => {});
  await browser.close();
  process.exitCode = 1;
}
```
