# P6.6 — Privacy guardrails (submissions/reflections)

## Problem Frame

Learner free-text is persisted to the `lab_submissions` table by reflection/portfolio/sign-off/failure-log surfaces that **do not call Claude**, so P6.3 (which placed the shared `PiiNotice` on Claude-call surfaces) didn't cover them. This is where saved, champion/admin-readable learner text lives — the highest-value place to remind learners not to store real client/constituent PII.

## Decisions (resolved in brainstorm)

- **Teach-only, reuse the existing `PiiNotice`** (`src/components/PiiNotice.tsx`) — no content scanning, no blocking, no acknowledgment gate. Fully consistent with the P6.3 warn-only decision. The plan-text word "enforced" is realized as **"consistently reminded everywhere learner text is captured"**, not scan/block.
- Do **not** add PII detection/enforcement (rejected: brittle, false positives on saved work, false confidence — can't detect names/addresses; and it would diverge from P6.3).

## Requirements

- R1. Place the shared `PiiNotice` on every persist-to-DB free-text learner surface not already covered by P6.3: **ReflectionCapture** (1.8/1.11), **FailureLog** (2.9), **UseCasePortfolio** (2.11), and **SignoffChecklist** (1.13) *if it has a free-text field* (confirm in planning; if it's checkbox-only, PII risk is negligible and it may be skipped).
- R2. Reuse the existing `PiiNotice` component **unchanged** (single source of truth for the copy); no new component, no props beyond the existing optional `className`.
- R3. Purely presentational — no change to save/record/gating logic; no scanning, no blocking, no persistence, no new network calls.

## Success Criteria
- Every persist-to-DB free-text learner surface shows the PII reminder near its input.
- Behavior is consistent with P6.3 (teach-only) — no call/save is blocked or altered.
- Together with P6.3, **all learner free-text capture points** (whether they go to Claude or the DB) carry the reminder.

## Scope Boundaries
- Teach-only; no PII scanning, blocking, or acknowledgment gate.
- Only the persist-to-DB free-text surfaces not already covered by P6.3 (the Claude-call surfaces are done).
- No change to the `PiiNotice` component itself, to storage, or to RLS.

## Key Decisions
- Consistency with P6.3 over stronger enforcement: one coherent teach-everywhere posture is simpler to maintain and honest about detection limits.
